# Zoo Management System 🐾

A web-based Zoo Management System built using Flask.

## Features
- Animal Management
- Employee Management
- Visitor Tracking
- Ticket System
- Feed Scheduling
- Login Authentication

## Tech Stack
- Python (Flask)
- SQLite
- HTML, CSS, Bootstrap

## Deployment
Hosted on Render
